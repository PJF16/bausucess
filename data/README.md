# Standardisierte Leistungsbeschreibung Hochbau

`lb-hb-023.json` enthält die Positionen der **LB-HB 023**, herausgegeben
vom Bundesministerium für Wirtschaft, Energie und Tourismus (BMWET), im
Format der ÖNORM A 2063:2021. Quelle ist der offizielle Datenträger
`LB-HB-023-2021.onlb`, Version 023 vom 31. Dezember 2025.

Quelle und Nutzungsbedingungen:
https://www.bmwet.gv.at/Services/Bauservice/Hochbau.html

Die Texte werden inhaltlich unverändert gespeichert. Das Skript
`scripts/import-lb-hb.ts` wandelt lediglich die XML-Struktur in einen für die
Suche kompakten JSON-Datensatz um.
